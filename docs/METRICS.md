# 指标字典

## 公共范围

`@start_date <= order_purchase_timestamp < @end_date`，起止均为每月第一天。边界为半开区间，时间按源文件无时区 DATETIME 原样解释，不转换到 UTC；清单生成时间则明确使用 UTC。订单按购买月归属，非交付月。

默认区间 `[2017-01-01, 2018-09-01)`；2016 年边缘小样本月份和 2018 年后续边缘月份不进入主报表，但第 12 个查询保留完整覆盖审计。数据快照末端有未完成订单，默认范围也不能消除右截尾偏差。

## 经营指标

| 指标/字段 | 公式 | 纳入规则与注意事项 |
| --- | --- | --- |
| commerce_eligible | status = delivered 且 item_count > 0 | 包含价格为 0 的有效明细；排除无明细订单 |
| 月订单量 orders | COUNT(订单) | 仅 commerce_eligible，不是明细行数 |
| item_gmv | SUM(明细 price) | 商品交易额，BRL，不含运费、无抽佣及退款推算 |
| freight_value | SUM(明细 freight_value) | 运费单列，不能叫平台收入 |
| avg_order_value | 月商品 GMV / 月订单量 | 不包含运费；订单数为 0 时为 NULL |
| payment_value | SUM(支付记录 payment_value) | 每单先聚合，支付不代表商品 GMV |
| 环比 | 本月 / 上月 - 1 | 用月份日历补齐零订单月份；首月或上月为 0 时 NULL |
| 品类 GMV 占比 | 品类商品金额 / 所有品类商品金额 | 金额可加；品类内订单数相互重叠，不可加 |
| 状态订单量 | 每种状态的 COUNT(*) | 所有状态，仅查询 02，不沿用已交付 GMV 口径 |

这套 GMV 更准确地描述“历史快照中最终已交付订单的商品交易额”，不是按会计准则确认的收入。没有订单状态变更历史，因此无法重建某个月末当时已知的交付状态。

## 配送指标

`delivery_eligible = 1` 要求：状态已交付；实际送达与预计送达时间均存在；两者均不早于购买时间。否则配送指标为 NULL，不当作准时订单。其他时间异常（例如承运时间异常）在质量报告中列出，不额外改变这项口径。

| 指标/字段 | 公式或含义 |
| --- | --- |
| delay_days_signed | DATEDIFF(实际送达日期, 预计送达日期)，负数为提前 |
| delay_days | MAX(delay_days_signed, 0) |
| is_late | 实际送达日期 > 预计送达日期为 1，否则 0 |
| late_rate | eligible 中 is_late 的平均值，即迟到订单 / 可判定订单 |
| avg_days_among_late | 仅 is_late=1 的 delay_days 平均值 |
| delivery_days | DATEDIFF(实际送达日期, 购买日期) |
| 地区 | 客户州 customer_state，缺失用 unknown |

预计日期通常按日期表达，因此本版自然日口径允许预计当天晚上送达。若要分析小时级 SLA，需另定义指标；不能与本指标混用。

卖家查询先使用 distinct seller_id + order_id 桥接，避免同卖家多明细重复计单。一个订单含多个卖家时，每个卖家均关联此订单，但该订单只提供一组送达时间。`single_seller_late_rate` 是单卖家订单敏感性比较，其分母 `single_seller_orders` 一并展示；并不支持卖家责任归因。不能将各卖家参与订单数相加作为全局订单总数。

## 客户体验指标

| 指标 | 定义 |
| --- | --- |
| 最新评价 | 见 v_reviews_latest 的确定性排序；所有评分先通过 1–5 检查 |
| 差评 | 最新评价 1 或 2 分 |
| 延迟区间 | 准时/提前、迟到 1–3 天、4–7 天、8–14 天、15 天及以上 |
| eligible_orders | 满足配送口径的订单数 |
| reviewed_orders | eligible 中有评分的订单数 |
| bad_reviews | reviewed 中差评的订单数 |
| bad_review_rate | bad_reviews / reviewed_orders，无评价时 NULL |
| review_coverage | reviewed_orders / eligible_orders |
| 分层差值 | 同州同购买月：迟到组差评率 - 准时组差评率 |

`MIN_ORDERS=30` 用于州/卖家履约组的可判定订单量、品类延迟组的已评价订单量，以及州×月组两边各自已评价订单量。SQL 08 的全局区间比较不抑制小组，便于观察完整分布；必须同时查看样本数，不能只看率。

评价是订单级，跨品类订单在各品类内各贡献一次评价，因此组间有重叠。品类细分不意味着获得了品类级真实评分。评价覆盖不随机，延迟可能与地区、旺季、品类等因素共同变化，结果仅表示相关性。

## 支付对账

质量检查只对“有商品且有支付”的订单统计商品加运费与支付金额差异大于 0.01 BRL 的数量（WARN）。查询 11 则包含所有经营口径订单，并单列缺支付订单与差异，允许暴露覆盖不一致。**商品表到订单视图的金额守恒是硬检查；商品加运费与支付金额的差异是业务审计**，两者不能混淆。

分母为零的率和均值均为 NULL；数量为 0 和指标未知有不同含义，报告不会把未知值画成 0。
